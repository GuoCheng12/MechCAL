# Development Snapshot

This branch synchronizes production modules, prompts and evaluation resources
present on 2026-10-31. Public `main` is unchanged. This is not a new versioned
release and makes no new performance claim.

Changes include native operation contracts, case-local evidence retrieval,
durable calculations, natural-language Worker/Reviewer explanations, atomic
argument/ranking edits, provisional confidence, source-aware citations and the
optional scientific backends in the README.

Production files under `mechcal/` are preserved byte-for-byte. The public 119-case
inputs and MIT license are retained. Portable examples and setup documentation
are separate additions, not a copy of private experiment launchers.

Excluded: credentials, relay settings, model outputs, checkpoints, raw calculations,
weights, paper/SI files, hidden references, internal diagnostic notes and external
binaries/parameters. Portable regression tests are included; private archive and
unbundled numerical-fixture tests remain local.

The latest online citation check reached a valid formal submission and successful
Reviewer reads, but not the complete review/response/finalization cycle. A broader
experiment was launched separately; this snapshot does not assert its outcome.
Offline tests and API success do not certify mechanism or evidence quality.
