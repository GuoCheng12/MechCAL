# 開發報告：C1 驗證、運行中發現的問題、C2

日期：2026-11-13（夜間接管）。開發集 17 個案例，測試集未動。評審：DeepSeek flash（高推理檔位，開發期設定）。
所有排名分數只作粗略參考（見 `docs/mechcal-iteration-plan-zh.md`：現有數據集分布偏斜、樣本小）。

## 一句話結論

**C1 消除了「證據容易拿到就排得高」的偏差，但排名變成由教授的先驗決定，證據在總體上沒有改變排名。**
同一個模型不用工具直接回答（Direct），排名不比 MechCAL 差（差距不顯著），但 MechCAL 的「有證據支持的排名」明顯更好（ES-nDCG +0.19，顯著）。
運行中發現並修好了 5 個和數據集無關的問題：成本日誌倍增、案例編號洩漏、基線成本資訊不對等、基線遇到無效回覆就崩潰、TD-DFTB 求解器對約四成分子失敗。
C2 讓證據的「區分性」有數據依據（參考面板）；第一次重複裡，證據第一次讓排名比只用先驗更好。
C3 讓先驗獨立於工具給出、多次取平均，針對排名不穩定的根源。C2、C3 的完整結果見第六節（部分仍在運行）。

## 三、C1 結果（dev4a + dev4b，34 次運行，代碼 628592c）

### 3.1 和數據集無關的訊號

| 訊號 | dev3（W1） | dev4（C1） |
|---|---|---|
| 中斷 / 沒有答案 | 0 / 0 | 0 / 0 |
| 計算型陳述有根據率 | 517/517 | 433/433 |
| 編造 | 0 | 0 |
| 浪費的委派（工具不適用） | 0 | 0 |
| 學生自修成功率 | 15/47 | 19/46 |
| 每個案例平均時間 / tokens | 22 分鐘 | 21 分鐘 / 70 萬 |
| **兩次重複的前三名重疊（Jaccard）** | **0.79** | **0.66** |

重複穩定性變差了。原因很清楚：**教授先驗的前三名在兩次重複之間的重疊也只有 0.66**，和最終答案一模一樣。同一個分子，兩次給出的先驗平均每個家族差 0.065，而很多家族的先驗彼此只差 0.05，所以前三名經常互換。現在的排名把先驗的隨機性直接傳到了答案。

### 3.2 「證據容易拿到就排得高」的偏差：基本消失

方法：看某個家族是否進了前三，按它「在不在參考答案裡」和「有沒有計算型證據」分組。

| | dev3 | dev4 |
|---|---|---|
| 不在參考答案、有計算證據 → 進前三 | 42% | 42% |
| 不在參考答案、沒有計算證據 → 進前三 | 4% | 2% |
| **在參考答案、沒有計算證據 → 進前三** | **0%（0/27）** | **16%（4/25）** |

dev3 時，一個家族只要沒有計算證據就**從不**進前三。dev4 裡這種情況開始出現。
再按先驗分層（dev4）：先驗前三的家族，有沒有計算證據，進前三的比例差不多（80% 對 50%，後者只有 4 例）；先驗排在後面的家族，有計算證據時偶爾被拉上來（15%），沒有時幾乎不會（1%）。也就是說，**進不進前三主要由先驗決定，證據的作用小了**。

### 3.3 新的問題：證據在總體上沒有改變排名

| | top-1 主要 | R@3 | nDCG@3 |
|---|---|---|---|
| 只用教授的先驗排序 | 0.471 | 0.498 | 0.565 |
| 最終答案 | 0.471 | 0.502 | 0.564 |

34 次運行中有 15 次證據改變了前三名，但加總起來效果為零。換句話說，**排名幾乎等於「看結構、憑化學常識給先驗」**。證據的作用目前主要是提供有根據的解釋，而不是比較和區分機制。

證據確實會把家族往下推（dev4a：最終相比第一步，上調 20 次、下調 27 次，ICT 被下調 10 次），所以不是只會確認。問題在於教授無法判斷哪些觀測是「普遍的」：

- 計算型陳述中 **72% 被標為 "partly"**（部分有區分性），"yes" 11%，"no" 17%。標記沒有提供多少資訊。
- **AGG 被高估**：被預測 25 次，參考答案裡只有 6 次（精確率 0.20）。dev4a 中 AGG 在 7 次運行裡被證據上調，依據是模型二聚體的 S1 紅移、激發在兩個分子上 50/50 分布。用 C2 的參考面板回頭看，這 7 次的二聚體 S1 紅移在常見發光分子中的百分位是 26、95、37、87、50、50、84：**全都是普通或比普通還弱的值**。

## 四、C2：讓「有沒有區分性」有數據依據

C1 留下的核心問題：教授不知道一個計算值對常見分子來說是普通還是罕見，只能憑感覺標 "partly"。C2 給出這個依據，而且不碰標籤、不寫死規則。

### 4.1 參考面板

- **43 個常見有機發光/吸光分子**：芳烴（苯到並四苯、芘、苝）、二苯乙烯、四苯乙烯、咔唑、三苯胺、DMABN、DANS、PRODAN、DCM、尼羅紅、香豆素、螢光素、羅丹明 B、BODIPY、花菁、萘酰亞胺、苝二酰亞胺、二苯甲酮、氧雜蒽酮、偶氮苯、3-羥基黃酮、水楊醛等。選擇標準是「常見例子」，不是按機制挑。凡是骨架（InChIKey 第一段）出現在基準任何案例（開發或測試）中的分子都自動排除（排除了 HBT）。
- 每個分子用**相同的配方和默認設置**跑一遍（不用 LLM，總計約 25 分鐘 CPU），得到 21 個標準描述量：S1 能量和振子強度、輻射速率估計、S2–S1 間隙、空穴-電子距離和重疊、扭轉能量範圍、最低振動頻率、溶劑響應、模型二聚體的結合能、S1 紅移、S1 振子強度、淨電荷轉移、S1–T1 間隙、SOC 等。
- 每個工具結果自動附上 `reference_panel`：這個值在面板中的百分位、面板中位數和四分位距。教授在每份學生報告裡都能看到；ReAct 也能看到（同一個工具閘道）。
- 面板沒有機制標籤，沒有金屬配合物（提示詞裡說明了）。

面板本身已經說明了一些事情：
- 模型二聚體的 S1 **通常**比單體低 0.25 eV（四分位距 0.12–0.60 eV），二聚體 S1 **通常**是暗的（振子強度中位數 0.0014）。所以「二聚體有紅移、最低態是暗的」對大多數分子都成立，不能作為 AGG 的區分性證據。
- 空穴-電子距離的中位數是 0.35 Å，5 Å（如 0047）在 95 百分位以上，才是真正罕見的電荷轉移。
- 開發集分子的空穴-電子距離大多落在面板的 80–100 百分位：這批分子比常見發光分子更偏電荷轉移型。

### 4.2 其他 C2 改動

- 第二節的 2、3、4、5 號修復。
- **先驗在第一個計算結果出來後固定**：dev4a 裡教授在看到證據後改了 61 次先驗，等於把證據重複計入先驗。現在系統保留原先驗，證據只能通過可信度起作用。
- 面板和參考值的打包、測試（全套回歸 3904 個通過）。

## 五、C3：先驗獨立給出、多次取平均

C1 的兩個數據都指向先驗：重複不穩定完全來自先驗（3.1），先驗本身又不如同一模型直接回答（3.5）。先驗本來就應該只依賴結構和化學常識，不應該依賴手上有哪些工具。

改法（提交 1468397，分支 `c3-priors`）：
- 教授開始之前，另外做 **3 次獨立的模型調用**，每次只給 SMILES、結構事實和家族定義（不給工具、不給 board），請它對 11 個家族各給一個先驗和一句理由。
- 取平均作為先驗，理由取最接近平均值的那一次；整個運行中固定。教授從這個先驗開始，只能調整可信度。
- 如果三次都失敗，退回 C2 的做法（教授自己給）。
- 成本：3 次調用約 1.4 萬 tokens（每個案例總量約 70 萬）。

在線冒煙（0047）：三次的先驗確實不同（例如 RIM 0.55 / 0.62 / 0.78，PET 0.28 / 0.35 / 0.58），平均能抵消一部分隨機性。

這個設計也讓之後的分析更乾淨：「只用先驗」就是一個加強版的 Direct，最終答案和它的差距就是證據的貢獻。
