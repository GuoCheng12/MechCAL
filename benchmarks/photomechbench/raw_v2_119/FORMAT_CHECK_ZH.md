## 本轮改动

1. 将不同重构阶段的格式统一为 `photomechbench.raw.v2`。
2. 补齐 11 个案例中空缺的来源标题，涉及 8 篇论文。标题来自已有 PDF，修改记录保存在 `metadata_repairs.json`。
3. 每个案例保留公开 SMILES、隐藏原文证据、参考标签、角色和完整机制判定，移除对本机 PDF 路径的依赖。
4. 导出 `public_inputs.jsonl`、`inputs.csv` 和 `references.jsonl`，附 JSON Schema、清单、校验结果与说明。
5. 增加扩展校验命令，可在新增案例后更新文件及统计，不将案例数量硬编码为 119。

与上一版 identity revision 相比，119 个保留案例的 SMILES、证据、标签和角色均未改变。
本轮没有新增科学判定，也没有运行模型推理、judge 或实验。

## 后续使用

`cases/` 是后续维护的完整记录。模型输入只取 `public_inputs.jsonl` 或 `inputs.csv`，不要把包含答案的完整 case 放入提示词。
机制池和任务提示词仍由运行器统一提供。参考机制数不限制为三个，三个是预测输出的数量。

扩展时复制一个新版本目录，沿用 schema，分配未使用且未被历史排除的 ID，并为新增案例填写真实来源及证据。
运行 `package_dataset validate 新目录 --refresh`，重新生成输入、参考、统计和校验清单，再更新版本号。
现有 119-case 目录保留作为基线快照。具体命令见 `DATASET_FORMAT.md`。

额外尝试完整 MechCAL CSV 读取器时，重构环境的 Python 3.10 在导入运行代码的 `datetime.UTC` 处失败。
CSV 字段和文件内容已通过独立检查，但本轮未完成整个运行器的加载验证；接实验时需使用 MechCAL 的 Python 3.11+ 运行环境。
这不影响当前数据包的格式校验和继续扩展。
